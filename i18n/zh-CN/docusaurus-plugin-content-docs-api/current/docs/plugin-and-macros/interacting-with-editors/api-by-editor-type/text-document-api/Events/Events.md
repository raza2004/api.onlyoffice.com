# 事件

| 事件 | 描述 |
| ----- | ----------- |
| [onAddComment](./onAddComment.md) | 使用 [AddComment](../../text-document-api/Methods/AddComment.md) 方法向文档中添加注释时调用的函数。 |
| [onBlurAnnotation](./onBlurAnnotation.md) | 注释失去焦点时调用的函数。 |
| [onBlurContentControl](./onBlurContentControl.md) | 显示哪个内容控件已失焦时调用的函数。 |
| [onChangeCommentData](./onChangeCommentData.md) | 使用 [ChangeComment](../../text-document-api/Methods/ChangeComment.md) 方法更改指定注释时调用的函数。 |
| [onChangeContentControl](./onChangeContentControl.md) | 显示哪个内容控件已更改时调用的函数。 |
| [onChangeCurrentPage](./onChangeCurrentPage.md) | 当前页面更改时调用的函数。 |
| [onChangeRestrictions](./onChangeRestrictions.md) | 编辑器中的限制更改时调用的函数。 |
| [onClick](./onClick.md) | 用户单击元素时调用的函数。 |
| [onClickAnnotation](./onClickAnnotation.md) | 用户单击注释时调用的函数。 |
| [onDocumentContentReady](./onDocumentContentReady.md) | 文档完全加载后调用的函数。 |
| [onEnableMouseEvent](./onEnableMouseEvent.md) | 用于打开/关闭鼠标或触控板事件的函数。 |
| [onExternalMouseUp](./onExternalMouseUp.md) | 在插件 iframe 外部释放鼠标按键时调用的函数。 |
| [onFocusAnnotation](./onFocusAnnotation.md) | 注释获得焦点时调用的函数。 |
| [onFocusContentControl](./onFocusContentControl.md) | 显示哪个内容控件已获得焦点时调用的函数。 |
| [onHideContentControlTrack](./onHideContentControlTrack.md) | 内容控件在文档中失去焦点时调用的函数。 |
| [onInsertOleObjects](./onInsertOleObjects.md) | 向文档中插入一个或多个 OLE 对象时调用的函数。 |
| [onParagraphText](./onParagraphText.md) | 文档中段落文本更新时调用的函数。 |
| [onRemoveComment](./onRemoveComment.md) | 使用 [RemoveComments](../../text-document-api/Methods/RemoveComments.md) 方法移除指定注释时调用的函数。 |
| [onShowContentControlTrack](./onShowContentControlTrack.md) | 内容控件获得焦点且其轨迹显示时调用的函数。 |
| [onSubmitForm](./onSubmitForm.md) | 用户单击"完成并提交"按钮时调用的函数。 |
| [onTargetPositionChanged](./onTargetPositionChanged.md) | 编辑器中目标位置更改时调用的函数。 |
